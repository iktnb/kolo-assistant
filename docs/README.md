# Коло — документація

Індивідуальний навчальний проєкт. Автор — **Басюк Юрій**.

«Коло» допомагає зберігати контакти, знаходити нотатки та бачити найближчі дні народження. Це один самостійний український застосунок для термінала: інтерфейс, бізнес-правила й локальне сховище містяться в одному репозиторії та запускаються одним процесом.

[Репозиторій на GitHub](https://github.com/iktnb/kolo-assistant) · [Головний README](../README.md)

## Що реалізовано

- Контакти з іменем, адресою, кількома телефонами, email і датою народження; перевірка значень, пошук, редагування та видалення.
- Нотатки з багаторядковим текстом; пошук, редагування й видалення.
- Додаткові можливості: нормалізовані теги нотаток, точний пошук за тегом і сортування за набором тегів.
- Найближчі дні народження в межах заданих 0–366 днів включно.
- Постійне SQLite-сховище в папці користувача, повноекранне керування клавіатурою, окремі команди для сценаріїв і безпечна демонстрація.

Повна відповідність основним вимогам і обом додатковим можливостям наведена в [матриці](requirements-coverage.md), разом із конкретними перевірками.

## Як запускати й чого очікувати

Підтримуване середовище — Linux або Ubuntu WSL, Python 3.12 і `uv`. Початкова підготовка залежностей може потребувати інтернету; користування застосунком після підготовки працює офлайн. Для меню потрібен справжній термінал.

Звичайний запуск відкриває повноекранний інтерфейс. `demo` використовує окремі тимчасові вигадані записи, а командні дії читають те саме сховище, що й звичайний інтерфейс. [Установлення та перші кроки](user-guide.md).

Окремих вебфронтенду, серверного бекенду, ML-компонента чи браузерного розгортання немає. Посилання на GitHub веде до коду й документації; застосунок запускається локально.
