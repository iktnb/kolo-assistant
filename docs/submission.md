# Повідомлення ментору

Привіт! Передаю індивідуальний проєкт «Коло» — персональний помічник з інтерфейсом командного рядка.

🔹 **Репозиторій:**

- [Коло — код застосунку, інтерфейс і тести](https://github.com/iktnb/kolo-assistant)

Увесь термінальний застосунок міститься в одному репозиторії.

🔹 **Демонстрація:**

- Локальний запуск у Linux або Ubuntu WSL. Після встановлення залежностей: `uv run --no-sync kolo demo`.
- [Установлення й запуск](https://github.com/iktnb/kolo-assistant/blob/main/docs/user-guide.md)

🔹 **Додатково:**

- [Документація](https://github.com/iktnb/kolo-assistant/blob/main/docs/README.md)
- [Презентація](https://docs.google.com/presentation/d/1god4xsRMEG-Jn7EKeBSf2oec52FZeyj44U5__ALga_w)
- [Відповідність вимогам завдання](https://github.com/iktnb/kolo-assistant/blob/main/docs/requirements-coverage.md)

Реалізовано контакти з валідацією, пошуком, редагуванням і видаленням, найближчі дні народження, текстові нотатки й теги. Дані зберігаються локально між запусками. Доступне повноекранне керування клавіатурою.
