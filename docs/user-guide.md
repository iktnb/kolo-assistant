# Посібник користувача

[Документація](README.md) · [Демонстрація за 3–5 хвилин](demo-guide.md) · [Повний README](../README.md)

## Установлення й запуск

Потрібні Linux або Ubuntu WSL, Python **3.12** і [uv](https://docs.astral.sh/uv/). У Windows відкрийте термінал Ubuntu WSL і виконайте ці команди всередині Linux; бажано зберігати проєкт і дані у файловій системі Linux.

```sh
git clone https://github.com/iktnb/kolo-assistant.git
cd kolo-assistant
uv sync --locked --all-groups
uv run --no-sync kolo --version
uv run --no-sync kolo demo
```

`uv sync` готує середовище й може потребувати інтернету. Після цього `--no-sync` запускає вже підготовлену версію; сам застосунок працює офлайн. Подальші приклади виконуються з кореня клонованого репозиторію.

`demo` показує позначку демонстрації та шлях тимчасового сховища. Воно містить вигадані записи, не читає особисті дані й прибирається після звичайного виходу. Кожен наступний запуск починається заново. `demo` не приймає `--data-dir`.

Для власних записів і довідки:

```sh
uv run --no-sync kolo
uv run --no-sync kolo --help
uv run --no-sync kolo notes edit --help
```

Меню та демонстрація потребують справжнього термінала. Командні дії працюють також із перенаправленим вводом/виводом.

## Клавіатура та перші дії

| Клавіша | Поведінка |
| --- | --- |
| ↑ / ↓, потім Enter | Вибрати розділ або запис і відкрити його |
| Tab / Shift+Tab | Наступне / попереднє поле чи кнопка |
| Enter на кнопці | Виконати її дію |
| Esc або «Назад» | Повернутися; Esc спершу закриває відкритий вибір або підтвердження |
| Ctrl+S | Зберегти форму |
| F2 у контактах/нотатках | Відкрити форму додавання |
| F1 поза формою | Відкрити довідку |
| Ctrl+Q / Ctrl+C | Запросити вихід із підтвердженням |

У полі тексту стрілки рухають курсор; у багаторядковому редакторі Enter додає рядок, а Tab переходить до наступного елемента. Enter у полі не зберігає форму. Поточний фокус позначено рамкою або виділенням; Tab дозволяє дістатися дій і у вузькому вікні.

1. Відкрийте «Контакти», виберіть «Додати» або F2. Укажіть ім’я; решту полів можна залишити порожніми. Кілька телефонів вводьте по одному на рядок.
2. Збережіть через Ctrl+S або «Зберегти». Виберіть запис і натисніть Enter: деталі містять усі поля, «Редагувати», «Видалити» й «Назад». Вводити ID в цьому інтерфейсі не потрібно.
3. У «Нотатках» створіть заголовок і текст; теги вводьте по одному на рядок. Для видалення необов’язкового значення під час редагування очистіть відповідне поле; порожнє поле тегів прибирає всі теги.

Однакові імена та заголовки дозволені; додаткові дані й незмінний ID розрізняють записи. «Назад» зберігає запит, фільтри, порядок і позицію списку. Збережений запис вибирається автоматично; якщо він не відповідає фільтру, з’являється пояснення.

## Пошук, теги й календар

Пошук контактів перевіряє ім’я, адресу, email і цифри телефону. Пошук нотаток — заголовок і текст без урахування регістру. Запит застосовується через Enter або «Застосувати».

Для нотаток можна поєднати текст із **точним нормалізованим тегом**: мають виконуватися обидві умови. Виберіть сортування «Заголовок» або «Теги» й застосуйте. За тегами записи впорядковано за набором тегів, далі за заголовком та ID; нотатки без тегів ідуть останніми. «Очистити фільтри» повертає всі записи й типовий порядок.

Головний екран показує дні народження за 7 днів. У відповідному розділі можна застосувати ціле число **0–366**: включено сьогодні й останню дату проміжку; 0 означає лише сьогодні. Кожен контакт показується один раз із найближчою річницею. Для 29 лютого у невисокосному році використовується 28 лютого, у високосному — 29; збережена дата незмінна. Enter на рядку відкриває контакт.

## Поля та перевірки

| Поле | Правило |
| --- | --- |
| Ім’я / заголовок | 1–120 символів після обрізання крайніх пробілів |
| Телефон | 10–15 цифр `0–9` і необов’язковий початковий `+`; пробіли, дужки й дефіси прибираються |
| Адреса / email | Необов’язкові; до 500 / 254 символів; email — ASCII у звичайному форматі `name@example.com` |
| Дата народження | Справжня дата `YYYY-MM-DD`, не в майбутньому |
| Текст нотатки | 1–10000 символів, не лише пробіли; початкові та кінцеві порожні рядки зберігаються |
| Тег | До 40 символів; пробіли по краях прибираються, регістр нормалізується, повтори усуваються; кома є частиною тегу |

Повтор телефона в одному контакті відхиляється; спільний номер у різних контактах дозволено. Існування email-скриньки не перевіряється. Для дат типовий пояс — `Europe/Kyiv`; `KOLO_TIMEZONE` приймає іншу IANA-назву, наприклад `UTC`.

## Видалення, помилки й вихід

Видалення показує назву та ID, початково фокусує «Залишити». Для видалення потрібно перейти до «Видалити» й підтвердити. Після видалення вибирається сусідній запис.

Помилка поля залишає чернетку й переводить фокус до проблемного поля. За збою збереження немає повідомлення про успіх: виправте причину й повторіть збереження. Помилка читання показує шлях і дії «Повторити», «Назад», «Вийти»; база не скидається.

Esc/«Назад» зі зміненої форми та Ctrl+Q/Ctrl+C потребують підтвердження втрати чернетки; початковий вибір — «Продовжити редагування». Вихід із чистого екрана також підтверджується. Esc на головному екрані відкриває підтвердження виходу.

`--plain` і `NO_COLOR` вимикають кольори, але залишають повноекранне керування та службові послідовності термінала. Для попереднього числового меню є глобальна опція `--line-mode` перед командою; його окремі правила наведено в [README](../README.md).

## Команди на окремих навчальних даних

Усі глобальні опції стоять перед командою. Цей каталог відокремлений від власного сховища; залиште термінал відкритим для наступних команд.

```sh
KOLO_DATA=$(mktemp -d /tmp/kolo-guide.XXXXXX)
uv run --no-sync kolo --data-dir "$KOLO_DATA" contacts add --name "Марія Приклад" --phone "+38 (067) 123-45-67" --email "maria@example.com" --birthday 1990-02-28
uv run --no-sync kolo --data-dir "$KOLO_DATA" contacts list --search "марія"
uv run --no-sync kolo --data-dir "$KOLO_DATA" notes add --title "План" --body "Підготувати демонстрацію" --tag Навчання
uv run --no-sync kolo --data-dir "$KOLO_DATA" notes list --search "демонстрацію" --tag навчання --sort tags
uv run --no-sync kolo --data-dir "$KOLO_DATA" birthdays --days 7
```

Для дій над записом CLI потребує повного ID. **Замініть приклади нижче на ID зі свого списку:**

```sh
CONTACT_ID=c_0123456789ab
NOTE_ID=n_0123456789ab
uv run --no-sync kolo --data-dir "$KOLO_DATA" contacts show "$CONTACT_ID"
uv run --no-sync kolo --data-dir "$KOLO_DATA" contacts edit "$CONTACT_ID" --address "Львів" --clear-email
uv run --no-sync kolo --data-dir "$KOLO_DATA" notes edit "$NOTE_ID" --clear-tags
uv run --no-sync kolo --data-dir "$KOLO_DATA" notes delete "$NOTE_ID" --yes
uv run --no-sync kolo --data-dir "$KOLO_DATA" contacts delete "$CONTACT_ID" --yes
```

Пропущене поле не змінюється; `--phone` замінює весь список телефонів, `--tag` — весь набір тегів. Для очищення є `--clear-phones`, `--clear-address`, `--clear-email`, `--clear-birthday` і `--clear-tags`. Видалення без `--yes` відхиляється. [Багаторядкові файли/stdin та повний CLI](../README.md).

Результат іде у stdout, помилка — у stderr. Коди завершення команд: 0 — успіх, 2 — неправильний ввід/відсутній ID/непідтверджене видалення, 1 — помилка сховища, 130 — переривання. Команди не запитують прихованого підтвердження й не зберігають частину неправильного редагування.

## Де дані та як зробити копію

Файл — `kolo.sqlite3`. Пріоритет каталогу:

1. Явний `--data-dir`; відносний шлях рахується від каталогу запуску.
2. Непорожній абсолютний `XDG_DATA_HOME` плюс `/kolo`; відносний XDG ігнорується.
3. `~/.local/share/kolo`.

Нові каталоги мають права 0700, база — 0600. Дані не шифруються й не надсилаються мережею. Використовуйте файлову систему Linux/WSL із hard links і fsync. Пошкодження, невідома версія чи відмова доступу показують помилку без скидання файлу; автоматичного ремонту немає.

Закрийте всі сеанси й скопіюйте **весь фактичний каталог даних**. Для типового шляху без `XDG_DATA_HOME` та `--data-dir`:

```sh
cp -a "$HOME/.local/share/kolo" "$HOME/.local/share/kolo-backup-$(date +%Y%m%d-%H%M%S)"
```

Копія містить відкриті особисті дані. Для іншого каталогу копіюйте саме його. Імпорт/експорт, синхронізація, фонові нагадування, автоматичні міграції формату та одночасне спільне редагування не підтримуються.
